# ML Archive

This directory contains superseded machine-learning implementations and
artifacts that were moved out of the active `ml/grading_forecast/` workflow.

Archived files are retained for reference only. They are not imported by the
current V3 grading, Phase 5 forecasting, Phase 6 decision engine, or Phase 7
backend runtime. Historical scripts may contain paths that refer to their
original locations; restore the relevant archived tree before attempting to
reproduce an old experiment.

Current ML code remains under `ml/grading_forecast/`.
