# Historical Evidence Records

These files preserve V1/V2/PP2 dataset, model, limitation, integration, and
result evidence. They remain relevant for research chronology and
reproducibility, but they are not the authoritative current workflow.

| File | Historical role |
|---|---|
| `dataset_preparation_phase.md` | V1/V2 dataset-preparation record |
| `model_training_phase.md` | V1/V2 model-training record |
| `price_dataset_description.md` | V2 price-dataset description |
| `PP2_INTEGRATION_VALIDATION.md` | PP2 backend integration evidence |
| `PP2_LIMITATIONS.md` | PP2 research and deployment limitations |
| `PP2_RESULTS.md` | Consolidated PP2 result evidence |
