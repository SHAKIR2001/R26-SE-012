# Historical Research Documents

This directory contains V1, V2, and PP2-era documents that no longer define
the current V3, Phase 5, Phase 6, or Phase 7 workflow.

- `status/` contains dated plans, checklists, project-status snapshots, and
  progress reports.
- `evidence/` contains historical dataset, model, limitation, integration, and
  PP2 result records.

The documents are preserved as research provenance. References inside them may
retain their original repository paths because they describe the repository at
the time the evidence was recorded. For the current workflow, start with
`../FULL_COMPONENT_PROGRESS_REPORT_2026-10-10.md`,
`../../guides/project_commands_guide.md`, and the V3/Phase 4-7 result documents.
