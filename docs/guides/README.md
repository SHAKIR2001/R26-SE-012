# Current Repository Guides

Status basis: current repository source and recorded verification through
2026-10-18.

These documents describe how to build, run, inspect, and validate the current
repository and its research/application workflow. They are operational guides
and indexes, not frozen result records.

| Guide | Purpose |
|---|---|
| `project_commands_guide.md` | Start here: current backend, API, Flutter, test, and research-safety commands |
| `PHASE7_APPLICATION_RUN_GUIDE.md` | Detailed Phase 7 browser, emulator, device, and acceptance procedure |
| `build_guide.md` | Android build, signing, installation, and distribution guidance |
| `repository_inventory.md` | Repository-wide ownership, authority, history, and cleanup map |

The guides describe procedures; they are not frozen research evidence. For
research conclusions and frozen results, use the V3 and Phase 4-7 documents
under `../research/`. Superseded V1/V2/PP2 records are under
`../research/historical/`.
